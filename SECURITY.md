# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately instead of opening a public GitHub issue.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any relevant logs or screenshots

Do not include passwords, API keys, private keys, OCIDs, tokens, or other sensitive credentials in the report.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

Security fixes will be applied to supported versions when applicable.
